## 과제 1

### (1) 올린 것 — **두 질의 모두 건수 5, 불일치 없음. 목록도 5건**

질의 2형태 각각 HTTP 200 / 건수 **5**. 이번엔 건수 불일치가 없고, **처음으로 목록이 건수와 같은 5건을 찍었다.**

| id | published_at | reactions | comments |

| 4415595 | 2026-08-17T07:35:35Z | 0 | 1 |
| 4414332 | 2026-08-17T05:16:16Z | 0 | 0 |
| 4409952 | 2026-08-16T12:08:42Z | 0 | 0 |
| 4407796 | 2026-08-16T03:09:05Z | 0 | 0 |

직전 회차 목록(3건)에 없던 id는 `4420796`, `4415595` 두 건이고, 둘 다 발행 시각이 당시 최신 id(4414332, 08-17 05:16Z)보다 **뒤**다. 다만 이 2건이 그때 「5」에 잡혀 있던 바로 그 2건인지는 원자료가 말하지 않는다 — **미확인**.

여전히 목록은 질의별로 분리돼 있지 않아, 두 질의가 **같은** 5개 id를 냈는지는 **미확인**. 직전 세 회차가 요구한 「질의별 id 병기 + 개별 `GET /api/articles/<id>`」는 이번 원자료에도 **없다 → 네 회차 연속 미반영**. 다만 그 요구가 겨냥한 증상(5≠3, 차이 id 미확인)은 이번 실측에서 소멸했다.

### (2) 회신 — **댓글 2 (첫 비영 관측)**

- 두 신규 id는 직전 회차 목록에 없었으므로 기준선이 없다 → **증가분 미확인**(첫 관측치가 1이다). 계정 전체 댓글 합계는 **2**, 반응 합계는 **0**.

## 과제 3 — 다음에 할 단 하나

**`4420796`과 `4415595`의 댓글 본문을 원자료에 그대로 찍는다: `GET /api/comments?a_id=<id>` 응답에서 `id / created_at / 작성자 username / 본문 앞 200자`를 댓글마다 한 줄씩.**

- 왜 이것이 먼저인가: 다섯 회차 만에 처음으로 0이 아닌 회신이 나왔다. 그런데 지금 가진 건 **개수 1**뿐이라, 사람인지 봇/스팸인지, 글 내용에 대한 반응인지 아닌지 **가를 수 없다**. 이 판정 하나에 따라 「회신 0의 원인이 노출인가 글인가」가 처음으로 갈린다. 댓글은 시간이 지나면 삭제·수정될 수 있어 지금 안 찍으면 사라지는 값이고, 목록·태그 측정은 사라지지 않는다.
- **수용 기준(다음 회차가 검증):** 원자료에 두 id의 댓글이 각각 최소 한 줄(작성자·시각·본문)로 있다. 없으면 하네스가 다섯 회차째 값을 버린 것이고, 그때는 제안 대신 그 사실만 적는다.

노출·사용자 수: **미측정.**
